Trainieren vs. Merken

Block 1 — Wie KI funktioniert

Das wichtigste Missverständnis: "Je mehr ich chatte, desto besser wird ChatGPT."

❌

Trainieren

Geht nicht.

Das Modell (das "Gehirn") wurde von OpenAI trainiert. Das ist abgeschlossen. Deine Chats verändern das Modell nicht. Es wird nicht schlauer durch dich.

✅

Merken

Passiert.

ChatGPT speichert Notizzettel über dich: Erinnerungen, Personalisierung, Erkenntnisse aus alten Chats. Die werden bei jedem Chat mitgeschickt.

Merken ≠ Trainieren. Das Gehirn bleibt gleich, es bekommt nur einen Spickzettel dazu.
Aber: Dieser Spickzettel ist nicht zuverlässig. Deshalb alle Infos immer im Prompt mitgeben.

Einstellungen → Personalisierung → Erinnerungen: Dort siehst und steuerst du, was ChatGPT sich gemerkt hat.

Zwei Techniken, die den Unterschied machen

Block 4 — Techniken & Bausteine

🔍 Self Evaluation

Lass ChatGPT seinen eigenen Text prüfen, bevor du ihn übernimmst.

Schritt 1: Prompt abschicken, Text generieren Schritt 2: "Prüfe diesen Text: - Gibt es generische Floskeln? - Passt der Ton zum Kunden? - Fehlen wichtige Infos?" Schritt 3: "Überarbeite den Text basierend auf deiner Analyse."

Funktioniert wie ein eingebauter Lektor. Erstaunlich effektiv.

🔗 Prompt Chaining

Komplexe Aufgaben in kleine Schritte aufteilen. Jede Antwort füttert den nächsten Prompt.

Prompt 1: "Lies dieses Kunden-Briefing. Was sind die 3 Key Messages?" ➔ [Antwort: 3 Key Messages] Prompt 2: "Nutze diese Key Messages. Schreib einen PR-Text für Fachpresse." ➔ [Antwort: PR-Text] Prompt 3: "Kürze den Text auf max. 200 Wörter, behalte den Ton."

Gibt dir Kontrolle bei jedem Schritt. Fehler sofort erkennbar.
