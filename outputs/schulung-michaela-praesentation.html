Langzeitgedächtnis

🧠

✍️

Block 4 — Techniken & Bausteine

💬 Conversational

Wann: Du weißt noch nicht, wie das Ergebnis aussehen soll.

Schritt für Schritt im Dialog. Ideal für Brainstorming, Konzepte, Ideenfindung.

"Welche Kampagnenideen für einen Gartengeräte-Hersteller?" → "Ansatz 2 vertiefen..." → "5 Headlines dafür..."

🎯 Single Shot

Wann: Du weißt genau, was rauskommen soll.

Ein Prompt, fertiges Ergebnis. Reproduzierbar, skalierbar, weitergebbar.

Ein Prompt mit allen Infos → Auf Knopfdruck fertige Mail → Für jeden Kunden wiederverwendbar

🧠 Meta Prompting

Wann: Du willst, dass ChatGPT dir beim Prompten hilft.

Du beschreibst WAS du brauchst, und ChatGPT baut den Prompt FÜR dich.

"Ich muss eine Mail an einen Gartengeräte-Kunden schreiben. Erstelle mir einen strukturierten Prompt dafür mit allen Bausteinen."

Conversational für die Kreativphase. Single Shot für den Alltag. Meta Prompting wenn du nicht weißt, wie du anfangen sollst.

Zwei Techniken, die den Unterschied machen

Block 4 — Techniken & Bausteine

🔍 Self Evaluation

Lass ChatGPT seinen eigenen Text prüfen, bevor du ihn übernimmst.

Schritt 1: Prompt abschicken, Text generieren Schritt 2: "Prüfe diesen Text: - Gibt es generische Floskeln? - Passt der Ton zum Kunden? - Fehlen wichtige Infos?" Schritt 3: "Überarbeite den Text basierend auf deiner Analyse."

Funktioniert wie ein eingebauter Lektor. Erstaunlich effektiv.

🔗 Prompt Chaining

Komplexe Aufgaben in kleine Schritte aufteilen. Jede Antwort füttert den nächsten Prompt.

Prompt 1: "Lies dieses Kunden-Briefing. Was sind die 3 Key Messages?" → [Antwort: 3 Key Messages] Prompt 2: "Nutze diese Key Messages. Schreib einen PR-Text für Fachpresse." → [Antwort: PR-Text] Prompt 3: "Kürze den Text auf max. 200 Wörter, behalte den Ton."

Gibt dir Kontrolle bei jedem Schritt. Fehler sofort erkennbar.
